- 조회 조건: 성인 2인 1실 · USD · 2027-02-21~25 / 2027-07-18~22 각 4박
- 데이터 기준일: 2026-11-24
- 무료 공개 범위: 바다 형태·이동수단·성향·만타/고래상어 필터, 질문형 추천(5문항), 리조트 특징·장단점, 1박 예산 구간
