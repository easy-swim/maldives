# 몰디브 리조트 98곳 — 예산대·성향 비교 (무료 공개판 v3)

영업 중인 몰디브 리조트 98곳을 각 리조트 공식 홈페이지 예약엔진에서 직접 조회해 정리한 비교 페이지입니다.

- 사이트: https://easy-swim.github.io/maldives/
- 조회 조건: 성인 2인 1실 · USD · 2027-02-21~25 / 2027-07-18~22 각 4박
- 데이터 기준일: 2026-11-19~24 (98곳 전수 조회 · 87곳 요금 확보)
- 무료 공개 범위: 바다 형태·이동수단·성향·만타/고래상어 필터, **3분 진단**(여덟 개 질문 → 여행사에 보낼 요청서), 예산 계산기, 가이드, 최대 3곳 비교함, 리조트 특징·장단점, 1박 예산 구간
- 기준·방법 화면: 숫자를 어떻게 만들었고 무엇을 하지 않는지 공개
- 패키지 안내 화면: 59,000원 올인원 패키지(찜 3곳 + 맞춤 5곳 = 총 8곳 실측 요금표 + 1:1 줌 컨설팅) 안내 · 구글폼·오픈채팅·노션 상세페이지 링크
- 별도 제공(59,000원 패키지): 리조트별 정확한 2월·7월 비치/워터 1박 금액, 세금 포함 환산액, 7월 할인율

## 구조 (v3, 2026-11-26)

| 파일 | 역할 |
| --- | --- |
| `template_v3.html` | 화면 템플릿(HTML+CSS+JS 단일 파일). 데이터 자리에 `__MALDIVES_DATA__` 자리표시자 |
| `data.json` | 무료 공개용 데이터 98곳(예산 구간만 포함, 정확한 금액 없음) |
| `build_v3.py` | `template_v3.html` + `data.json` → `index.html` |
| `index.html` | 배포본(외부 라이브러리 없이 동작하는 단일 파일, 데이터 내장) |
| `make_template_v3.py` | 클로드 아티팩트 원본(`design-ref/claude/artifact_original.html`)에서 템플릿을 만든 기록(문구 수정 포함) |

문구를 고칠 때는 `template_v3.html`을 고치고 `python3 build_v3.py`로 `index.html`을 다시 만든 뒤 push 합니다.
(v2 시절 `build_v2.py`·`free_app.js`는 이력 보관용이며 v3 배포에는 쓰이지 않습니다.)

`assets/detail/card-01~05.png` 는 노션 상세페이지에 쓰는 카드 이미지입니다.

요금은 프로모션·재고·환율에 따라 달라집니다. 예약 전 공홈에서 다시 확인하세요.
